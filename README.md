# 🏦 پلتفرم درگاه کارت‌به‌کارت هوشمند بلوبات (BluBot)

این پروژه یک پلتفرم جامع، چندمستأجره (Multi-Tenant) و کاملاً خودکار برای ارائه خدمات **درگاه پرداخت کارت‌به‌کارت لحظه‌ای** ویژه فروشگاه‌های آنلاین، ربات‌های تلگرام و وب‌سایت‌ها بر پایه **نشست فعال وب (Active Web Session) بلوبانک** است.

## 🌟 ویژگی‌های کلیدی

* **وب‌سایت رسمی و پرتال تحت وب کامل:** شامل صفحه اصلی، مستندات API، داشبورد پذیرنده، پنل مدیریت کل و صفحه پرداخت خریدار.
* **عدم وابستگی به گوشی و سیم‌کارت:** بدون نیاز به گوشی فیزیکی یا برنامه‌های پیامک‌خوان (SMS Forwarder).
* **تطبیق خودکار واریزی با آفست چند تومانی:** تخصیص مبلغ نهایی تصادفی و یکتا برای هر فاکتور جهت تایید آنی.
* **استخراج کامل اطلاعات فیش:** نام واریزکننده، شماره کارت/شبا، کد پیگیری و مانده لحظه‌ای.
* **مدل اقتصادی و کارمزد تجاری:**
  * سیستم **کیف پول اعتباری (Prepaid Wallet)** درون پنل و ربات؛ کسر خودکار کارمزد از اعتبار فروشنده پس از تایید واریز خریدار.
  * کارمزد ۲٪ تا سقف ۳۵,۰۰۰ تومان (قابل تنظیم در پنل ادمین).
  * طرح ماه اول رایگان (کارمزد ۰) برای جذب سریع مشتریان.
* **ربات تلگرام پیشرفته:** مدیریت حساب بلوبانک، صدور فاکتور، شارژ کیف پول و پنل ادمین کل.

## 🖥 صفحات و بخش‌های وب‌سایت

| مسیر URL | عنوان صفحه | توضیحات |
| :--- | :--- | :--- |
| `/` | **صفحه اصلی (Landing Page)** | معرفی خدمات، مقایسه با SMS Forwarder، نمایش زنده عملکرد، تعرفه و سوالات متداول |
| `/miniapp` | **مینی‌اپ تلگرام (Mini App)** | ثبت‌نام هوشمند، مدیریت درگاه، کلیدهای API، اتصال بلوبانک، تنظیم وب‌هوک و ورود ۱ کلیکه به وب |
| `/documentation` | **مستندات فنی API** | راهنمای کامل برنامه‌نویسان با نمونه کدهای آماده PHP/ووکامرس، پایتون، نودجی‌اس و cURL |
| `/payment/{token}` | **صفحه پرداخت خریدار** | نمایش کارت بلوبانک، مبلغ دقیق با آفست، تایمر معکوس و فیش سبز واریز موفق |
| `/login` | **ورود به پنل (وب)** | ورود پذیرندگان ثبت‌نام‌شده با آیدی تلگرام یا کلید API (ثبت‌نام انحصاری از تلگرام) |
| `/dashboard` | **داشبورد پذیرنده** | مشاهده کلیدهای Live/Test، ثبت آدرس Webhook، صدور فاکتور، شارژ کیف پول و تاریخچه |
| `/admin` | **پنل مدیریت کل پلتفرم** | گزارش سود کارمزدها، کل گردش مالی عبوری، مدیریت کاربران و تنظیمات کارمزد |

## 🌐 قابلیت تنظیم دامنه اختصاصی (Custom Domain)

**بله، این سیستم کاملاً از دامنه اختصاصی پشتیبانی می‌کند!**
تمام لینک‌های پرداختی که برای خریداران تولید می‌شود (`/payment/{token}`) و آدرس‌های وب‌سرویس و وب‌هوک مستقیماً بر اساس دامنه‌ای که در متغیر `BASE_URL` قرار می‌دهید کار می‌کنند:

* مثال: اگر دامنه شما `pay.yoursite.com` باشد:
  * لینک صفحه پرداخت: `https://pay.yoursite.com/payment/01ARZ3NDEK...`
  * آدرس API: `https://pay.yoursite.com/api/v1/invoices/create`
  * مستندات خودکار: `https://pay.yoursite.com/docs`

## 🚂 آموزش گام‌به‌گام راه‌اندازی روی Railway.app

سرویس **Railway** یکی از بهترین پلتفرم‌های کلود برای اجرای این سیستم است زیرا از Dockerfile، متغیرهای محیطی، دیسک‌های پایدار (Volume)، و **دامنه اختصاصی با SSL رایگان** به صورت کامل پشتیبانی می‌کند.

### گام ۱: آپلود پروژه در GitHub
1. یک ریپازیتوری جدید (مثلاً خصوصی / Private) در گیت‌هاب خود بسازید.
2. کدهای این پوشه را در ریپازیتوری خود Push کنید:
```bash
git init
git add .
git commit -m "Initial commit of BluBot Platform"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/blubot.git
git push -u origin main
```

### گام ۲: ایجاد پروژه در Railway
1. وارد سایت [railway.app](https://railway.app) شوید و با اکانت GitHub خود لاگین کنید.
2. روی دکمه **New Project** کلیک کنید.
3. گزینه **Deploy from GitHub repo** را انتخاب کرده و ریپازیتوری ساخته‌شده را انتخاب کنید.
4. ریلوِی به طور خودکار فایل `Dockerfile` یا `Procfile` موجود در پروژه را شناسایی کرده و شروع به بیلد می‌کند.

### گام ۳: تنظیم متغیرهای محیطی (Variables)
در صفحه پروژه در Railway، وارد تب **Variables** شوید و مقادیر زیر را اضافه کنید:

| نام متغیر (Variable) | مقدار نمونه | توضیح |
| :--- | :--- | :--- |
| `BOT_TOKEN` | `7123456789:AAH...` | توکن ربات تلگرام دریافتی از BotFather@ |
| `ADMIN_TELEGRAM_ID` | `123456789` | آیدی عددی تلگرام شما برای دسترسی به پنل مدیریت |
| `BASE_URL` | `https://pay.yourdomain.com` | آدرس دامنه شما (یا دامنه رایگان Railway) |
| `ENCRYPTION_KEY` | *(تولید کلید تصادفی)* | کلید رمزنگاری AES نشست‌های بانکی |
| `DEFAULT_FEE_PERCENT` | `2.0` | درصد کارمزد پیش‌فرض پلتفرم |
| `DEFAULT_FEE_CAP` | `350000` | سقف کارمزد هر تراکنش (به ریال) |
| `FREE_TRIAL_DAYS` | `30` | تعداد روزهای رایگان ماه اول برای کاربران جدید |

> **نکته کلیدی:** پورت اجرایی سرور به صورت خودکار توسط ریلوی با متغیر `$PORT` تنظیم می‌شود و در کد پروژه شناسایی می‌گردد.

---

### گام ۴: اتصال دامنه اختصاصی (Custom Domain) در Railway
1. در داشبورد سرویس خود در Railway، به تب **Settings** بروید.
2. به بخش **Networking** یا **Public Networking** بروید.
3. روی دکمه **Custom Domain** کلیک کنید.
4. دامنه یا ساب‌دامنه مد نظر خود را وارد کنید (مثلاً `pay.yourdomain.com`).
5. ریلوی به شما یک رکورد **CNAME** می‌دهد (مثلاً `something.up.railway.app`).
6. وارد پنل مدیریت دامنه خود (مثل Cloudflare یا پنل هاست خود) شوید و رکورد CNAME را ثبت کنید:
   * **Type:** `CNAME`
   * **Name:** `pay`
   * **Target:** رکوردی که ریلوی داده است.
   *(اگر از Cloudflare استفاده می‌کنید، حالت پروکسی ابر نارنجی را خاموش یا روشن بگذارید، هر دو پشتیبانی می‌شود).*
7. ریلوی ظرف ۲ الی ۵ دقیقه گواهی امنیتی SSL رایگان (Let's Encrypt) صادر می‌کند و سایت با `https` فعال می‌شود!
8. در نهایت در تب **Variables** مقدار `BASE_URL` را برابر با دامنه جدید خود قرار دهید (مثلاً `https://pay.yourdomain.com`).

---

### گام ۵: ذخیره‌سازی پایدار دیتابیس در Railway (Volume)
کانتینرهای ابری پس از ری‌استارت فایل‌های محلی را ریست می‌کنند، برای اینکه دیتابیس SQLite (`blupal.db`) شما پاک نشود:
1. در داشبورد ریلوِی، روی سرویس خود کلیک راست کرده یا از منوی تنظیمات گزینه **Add Volume** را بزنید.
2. مسیر **Mount Path** را برابر با:
   ```
   /app/data
   ```
   قرار دهید.
3. در تب **Variables** مقدار دیتابیس را به مسیر ولوم تغییر دهید:
   ```env
   DATABASE_URL=sqlite+aiosqlite:////app/data/blupal.db
   ```
*(همچنین در صورت تمایل می‌توانید با یک کلیک از دیتابیس PostgreSQL ریلوِی نیز استفاده کنید).*

## 💻 راه‌اندازی به صورت لوکال یا سرور مجازی (VPS)

اگر مایلید پروژه را روی کامپیوتر خود یا سرور ابری اوبونتو اجرا کنید:

```bash
# ۱. نصب کتابخانه‌ها
pip install -r requirements.txt

# ۲. اجرای تست‌های تاییدیه
python test_system.py

# ۳. اجرای کامل
python main.py
```

سرویس‌ها به طور خودکار آماده کار خواهند بود:
* وب‌سرویس REST روی: `http://localhost:8000`
* مستندات آنلاین Swagger: `http://localhost:8000/docs`
* ربات تلگرام و واچر تراکنش‌ها در پس‌زمینه

## 📡 مستندات API برای اتصال فروشگاه‌ها

### ایجاد فاکتور (Create Invoice)
```bash
curl -X POST "https://pay.yourdomain.com/api/v1/invoices/create" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: blu_live_YOUR_KEY" \
  -d '{"amount": 1000000}'
```

### نمونه پاسخ سرور:
```json
{
  "success": true,
  "invoice_id": 123,
  "amount": 1000000,
  "final_amount": 1000245,
  "status": "PENDING",
  "payment_link": "https://pay.yourdomain.com/payment/01ARZ3NDEKTSV4RRFFQ69G5FAV",
  "card_number": "6219861012345678",
  "mode": "live",
  "expires_at": "2026-09-10T06:30:00+03:30"
}
```

### وب‌هوک ارسالی به فروشگاه پس از پرداخت (Webhook Delivery):
```json
{
  "success": true,
  "event": "payment.completed",
  "invoice_id": 123,
  "status": "PAID",
  "amount": 1000000,
  "final_amount": 1000245,
  "mode": "live",
  "payer_name": "علی رضایی",
  "payer_card": "6037991234567890",
  "payer_bank_name": "بانک ملی"
}
```
فروشگاه باید پس از دریافت وب‌هوک پاسخ HTTP 200 ارسال نماید.
