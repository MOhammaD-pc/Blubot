راهنمای اتصال به وب‌سرویس بلوبات (BluBot)

وب‌سرویس بلوبات به شما امکان می‌دهد سیستم پرداخت کارت‌به‌کارت هوشمند و آنی را در وب‌سایت، اپلیکیشن یا ربات تلگرام خود راه‌اندازی کنید. تمام تراکنش‌ها بر پایه استاندارد REST و با فرمت JSON تبادل می‌شوند.

آدرس پایه (Base URL):

{{ base_url }}/api/v1

احراز هویت (Authentication)

برای ارسال درخواست‌ها به وب‌سرویس، باید کلید API خود را که از داشبورد دریافت کرده‌اید در هدر X-API-Key ارسال فرمایید: 

X-API-Key: blu_live_YOUR_API_KEY

کلیدهای زنده با پیشوند blu_live_ و کلیدهای آزمایشی با پیشوند blu_test_ آغاز می‌شوند.

ایجاد فاکتور جدید

با فراخوانی این اندپوینت، یک فاکتور پرداخت ایجاد شده و شماره کارت بلوبانک به همراه مبلغ اختصاصی (با آفست چند تومانی) و لینک پرداخت به شما بازگردانده می‌شود.

POST /invoices/create
پارامترنوعاجباریتوضیحات
amountعدد (Integer)بلهمبلغ به ریال (حداقل ۱۰۰,۰۰۰ ریال)
card_numberرشته (String)خیرشماره کارت دلخواه از بین کارت‌های متصل

نمونه درخواست (cURL):

curl -X POST "{{ base_url }}/api/v1/invoices/create" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: blu_live_YOUR_KEY" \
  -d '{"amount": 1000000}'

نمونه پاسخ موفق:

{
  "success": true,
  "invoice_id": 123,
  "amount": 1000000,
  "final_amount": 1000245,
  "status": "PENDING",
  "payment_link": "{{ base_url }}/payment/01ARZ3NDEKTSV4RRFFQ69G5FAV",
  "card_number": "6219861012345678",
  "mode": "live",
  "expires_at": "2026-09-10T12:30:00+03:30"
}

استعلام وضعیت فاکتور

GET /invoices/{invoice_id}

وضعیت‌های ممکن فاکتور: PENDING (در انتظار پرداخت)، PAID (پرداخت شده)، EXPIRED (منقضی شده). 

{
  "success": true,
  "invoice_id": 123,
  "status": "PAID",
  "transaction_id": 123,
  "amount": 1000000,
  "final_amount": 1000245,
  "payer_name": "علی رضایی",
  "payer_card": "6037991234567890",
  "payer_bank_name": "بانک ملی"
}

شبیه‌سازی در محیط آزمایشی (سندباکس)

برای تست برنامه بدون نیاز به انتقال واقعی پول، با کلید آزمایشی blu_test_... فاکتور بسازید و سپس با اندپوینت زیر آن را شبیه‌سازی کنید: 

curl -X POST "{{ base_url }}/api/v1/sandbox/invoices/123/simulate" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: blu_test_YOUR_KEY" \
  -d '{"scenario": "success"}'

دریافت اعلان خودکار (Webhook)

به محض اینکه واریزی توسط سیستم تشخیص داده شود، یک درخواست POST با بدنه JSON به آدرس وب‌هوک فروشگاه شما ارسال می‌گردد. سرور شما باید پاسخ HTTP 200 ارسال کند: 

{
  "success": true,
  "event": "payment.completed",
  "invoice_id": 123,
  "status": "PAID",
  "amount": 1000000,
  "final_amount": 1000245,
  "payer_name": "علی رضایی",
  "payer_card": "6037991234567890",
  "payer_bank_name": "بانک ملی"
}

نمونه کدهای اتصال در زبان‌های مختلف

PHP (وردپرس / ووکامرس / اسکریپت اختصاصی):

<?php
// دریافت داده‌های وب‌هوک در PHP
$payload = json_decode(file_get_contents('php://input'), true);

if ($payload && isset($payload['event']) && $payload['event'] === 'payment.completed') {
    $invoice_id = $payload['invoice_id'];
    $payer_name = $payload['payer_name'];
    $final_amount = $payload['final_amount'];

    // ثبت پرداخت در دیتابیس سایت و افزایش موجودی
    
    http_response_code(200);
    echo json_encode(['received' => true]);
} else {
    http_response_code(400);
}
?>

Python (FastAPI / Flask / Django):

import requests

# ایجاد فاکتور جدید در پایتون
res = requests.post(
    "{{ base_url }}/api/v1/invoices/create",
    headers={"X-API-Key": "blu_live_YOUR_KEY"},
    json={"amount": 1000000}
)
data = res.json()
print("لینک پرداخت مشتری:", data["payment_link"])
